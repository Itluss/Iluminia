# Plan — Test de direction artistique "Brawl Stars" sur le menu (2026-08-05)

- Objectif : premier test concret de la nouvelle direction visuelle (validée
  avec Camille : style façon Brawl Stars — chibi, contours peints épais,
  cel-shading saturé), appliquée d'abord à `public/spike3d-menu.html`
  (PAS l'arène 3D cette itération).
- Portée volontairement réduite (règle du projet : jamais de génération en
  série sans validation intermédiaire) : UNIQUEMENT le fond du menu + le
  bouton "Jouer" (élément le plus visible). Le reste (autres boutons, états
  clic/hover, transitions, loaders, sliders) attend la validation de ce
  premier lot avant généralisation.
- Référence existante trouvée : `public/ui/interface.png` (bible graphique
  actuelle) — style pastel/storybook doux, PAS la direction Brawl Stars
  visée. Décision : génération SANS cette référence par défaut
  (`use_style_base: false`) pour ce test, afin de ne pas tirer le résultat
  vers l'ancien style ; prompt textuel explicite pour la nouvelle direction
  à la place. Aucune capture d'écran réelle de Brawl Stars fournie par
  Camille — généré à partir de la description du style (chibi, contours
  encre épais, cel-shading saturé, reflets glossy), à affiner si l'écart
  est trop grand.
- Assets prévus (2 images, moteur `openai` pour l'alpha natif) :
  1. `menu-bg-texture.png` — texture de fond plein cadre (pas de scène
     illustrée complexe pour ce premier test, un fond stylisé
     arène/lumières/confettis).
  2. `play-btn-bg.png` — forme du bouton "Jouer" en fond transparent (le
     texte "Jouer" reste du vrai DOM stylé par-dessus, comme `#menu-logo`
     déjà en text-stroke — jamais de texte figé dans une image).
- Changements fonctionnels : aucun. Changement visuel uniquement (fond +
  bouton Jouer).
- Risques : écart de style si le prompt ne capture pas bien "Brawl Stars"
  sans référence image réelle ; lisibilité du bouton à vérifier avec le
  texte DOM par-dessus.
- Hors périmètre (explicitement reporté) : arène 3D, autres boutons du
  menu (collection/cadeaux/avatar/familier), transitions, loaders, sliders,
  overlays (collection/wardrobe/familiar) — attendent la validation de ce
  test avant généralisation.
- Critère d'acceptation : amélioration visuelle nette vs. le dégradé CSS
  plat actuel, direction perçue comme cohérente avec "chibi/arène peinte",
  aucune régression fonctionnelle (bouton Jouer toujours cliquable, texte
  lisible).

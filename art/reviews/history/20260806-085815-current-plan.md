# Recomposition complète du lobby (2026-08-06)

Mission "REDESIGN COMPLET DU LOBBY MOBILE" — Camille jugeait le lobby
encore "pauvre et terne" malgré les passes précédentes ; benchmark Brawl
Stars fourni (analyse de principes, pas de copie). Résolution de référence
imposée : 844×390.

## 5 problèmes identifiés (avant code)

1. Personnage = placeholder évident (cercle+rectangle+2 bras rapportés,
   coutures visibles).
2. Pet anecdotique (~65px, collé dans un coin).
3. Fond sans identité (dégradé générique).
4. Une seule famille de forme partout (rectangle arrondi).
5. Composition trop symétrique/vide (grandes zones mortes).

## Changements

- **Palette harmonisée** (`theme.css`) — valeurs ajustées vers des teintes
  plus franches/lumineuses (mêmes noms de tokens, pas de rename global).
- **Lobby Background System en 4 couches** (dégradé / formes douces /
  motif propriétaire étoile+empreinte en SVG inline / sol), structuré pour
  qu'une couche puisse être remplacée par une vraie illustration plus tard
  sans toucher aux autres.
- **Personnage reconstruit** : tête (cercle existant) + silhouette de corps
  en UN SEUL path SVG (épaules/bras intégrés, aucune pièce rapportée) —
  remplace le montage à 3 pièces CSS d'un lot précédent.
- **Pet agrandi et mis en scène** : ~90-108px (contre ~65-82px), décalé
  avec sa propre ombre au sol, plus "collé au bord du perso".
- **Carte de mode** ajoutée à côté de Jouer — décrit le VRAI mode existant
  ("Arène des Elumins · Fractions CM1-CM2"), aucune fausse fonctionnalité
  inventée (pas de boutique/défi quotidien qui n'existe pas).
- **Bouton Jouer** : respiration idle très légère (animée sur `filter`, pas
  `transform`, pour ne jamais interférer avec l'effet d'appui existant).
- Boutons de nav, pastille niveau : inchangés dans cette passe (déjà
  conformes au gabarit demandé — 56px sur téléphone, dans la fourchette
  56-72px).

## Itérations (boucle capture → inspection → correction, avant le rendu final)

1. Corps en silhouette SVG : 1er essai → écart visible entre tête et corps
   (technique margin-top négatif incompatible avec le nouveau SVG).
2. Repositionnement en absolu explicite : tête aplatie en ovale (bug de
   spécificité CSS — `height` hérité de `.avatar-portrait` non réécrit).
3. Tailles explicites width+height sur les 2 axes : corps correct mais
   sans épaules (juste un ovale) → path SVG redessiné avec bosses
   d'épaules/bras intégrées.
4. Motif de fond trop visible → opacité réduite, tuile agrandie.

## Vérification

Audit sur 6 formats (740×360 → 1024×768) : scrollWidth/scrollHeight +
éléments hors-écran — 6/6 PASS, zéro erreur console.

## Hors périmètre / limites connues

- Tablette (1024×768) : composition correcte mais vide perceptible entre
  le duo perso/pet et les contrôles du bas — priorité moindre selon la
  consigne de Camille (844×390 = référence principale), non retravaillé
  davantage dans ce lot.
- Aucune ressource (pièces/gemmes) ajoutée — n'existe pas dans le jeu.

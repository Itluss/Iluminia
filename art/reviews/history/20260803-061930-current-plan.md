# Fiche d'itération — Suppression complète du menu inventaire

## Demande
Camille a jugé le menu inventaire pas assez professionnel (grille
quasi-vide, panneau de détail inachevé) malgré la correction des 3 bugs de
l'itération précédente, et a demandé sa suppression complète plutôt qu'une
nouvelle tentative.

## Changements
`public/spike3d-village.html` :
- Supprimé : `#inventory-overlay`/`#inventory-modal` (HTML), tout le CSS
  associé (`.inv-grid`, `.inv-slot`, `.inv-detail`, `.inv-footer`, etc.),
  toute la logique JS (`INV_ITEMS`, `selectInvItem`, `openInventory`,
  `closeInventory`, `updateInventoryPanel`, listeners), les entrées
  `__spikeDebug.openInventory`/`selectInvItem`.
- Bouton sac à dos de la barre de raccourcis : passé de actif à `disabled`
  (« Inventaire (à venir) »), cohérent avec les 3 autres boutons déjà
  désactivés (équipement/carte/réglages).
- Supprimé : `scripts/capture-inventory.mjs`, `scripts/compare-inventory.mjs`
  (dédiés au menu supprimé, non fonctionnels sans lui).

## Non touché
`progress.coins`/`progress.stars` restent affichés ailleurs dans le HUD
(panneau ressources haut-droite, barre XP) — uniquement le menu modal est
retiré. Les assets générés (`public/ui/generated/inventory-panel-banana.png`,
icônes) sont laissés sur disque, non référencés.

## Vérification
`npm run capture` : 0 erreur console, barre de raccourcis affichée avec ses
4 boutons désormais tous désactivés de façon cohérente, aucune régression
visible sur le reste du HUD.

## Historique
Tout le travail précédent sur ce menu (planche, tentatives de découpe,
génération banana, correctifs) reste récupérable via git — 2 commits de
sécurité créés avant les changements destructifs de cette session.

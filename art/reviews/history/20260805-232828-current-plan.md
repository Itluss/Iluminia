# Plan — Suppression du scroll dans les fenêtres modales (2026-08-05)

Camille : sur certains écrans il fallait scroller pour atteindre un bouton
(comparé à Brawl Stars où ça n'arrive jamais). Objectif : tout doit tenir
dans la fenêtre visible, aucun scroll requis pour une action.

## Audit (mesure scrollHeight - clientHeight à 740×360, le format le plus
contraint testé jusqu'ici)

- `#collection-card` : **303px de dépassement** (le pire, grille de pets sur
  2 colonnes fixes = 3 lignes).
- `#round-end .card` : **143px de dépassement** (podium + classement + XP +
  récompenses + 3 boutons, tout empilé verticalement).
- `#wardrobe-card` : **69px de dépassement** (grille 3 colonnes = 2 lignes).
- `#familiar-card` : **43px de dépassement** (bloc œuf empilé verticalement).
- `#gifts-card`, `#quiz-card` : 0px, déjà conformes, non touchés.

## Correction — utiliser la largeur du paysage au lieu d'empiler verticalement

- `#collection-card` / `#wardrobe-card` / `#familiar-card` : cartes
  élargies (420-460px → 560-640px), grilles passées de 2-3 colonnes fixes à
  `repeat(auto-fit, minmax(...))` — tous les éléments tiennent sur une seule
  ligne au lieu de 2-3, tailles/paddings légèrement resserrés.
- `#egg-block` (familiers) : passé d'un empilement vertical (icône, statut,
  barre, boutons chacun sur leur ligne) à une ligne horizontale (icône +
  statut + barre + boutons côte à côte, `flex-wrap` en secours).
- `#round-end .card` : restructuré en **2 colonnes** (gauche : podium +
  classement ; droite : gains XP/fragments/récompenses + les 3 boutons
  d'action) au lieu d'un empilement vertical unique. Carte élargie à 620px.

Aucune couleur/aucun composant graphique modifié — uniquement layout,
tailles de grille, espacements.

## Résultat mesuré (740×360)

`#collection-card` 303px → 3px. `#round-end .card` 143px → 1px.
`#wardrobe-card` 69px → 0px. `#familiar-card` 43px → 0px. Les 1-3px
restants sont un arrondi sous-pixel, invisibles/sans effet (pas de barre de
scroll déclenchée).

## Vérification

Captures des 4 fenêtres corrigées à 740×360 (le format le plus contraint),
zéro erreur console. `#gifts-card`/`#quiz-card` non retouchés (déjà à 0px).

# Fiche d'itération — jeu-2026 (2026-07-30)

- Demande : « Rendre le jeu beaucoup plus proche d'un jeu de 2026 : donner de
  la profondeur (jeu trop plat), plein écran, barre d'expérience, animer le
  personnage quand il se déplace. »
- Objectif utilisateur : sensation de production moderne, écran rempli,
  héros vivant.
- Expérience joueur attendue : plus de bandes noires ; le héros marche
  réellement (alternance de poses) ; les personnages rapetissent subtilement
  vers le fond (perspective 2.5D) ; barre d'XP lisible avec valeurs.
- Scènes/systèmes : config d'affichage, toutes les UI (positions dynamiques),
  Player/Lina/Fox (perspective + animation), Hud (barre XP).
- Changements fonctionnels : aucun sur quête/dialogue/inventaire/XP (valeurs).
- Changements visuels :
  1. PLEIN ÉCRAN — taille logique calculée sur le ratio de la fenêtre
     (hauteur 540 fixe, largeur = 540×ratio, borné 16:9 → 21:9), Scale.FIT :
     plus aucune bande noire sur les écrans courants. UI repositionnée en
     coordonnées dynamiques (scene.scale).
  2. PROFONDEUR — échelle des personnages fonction de Y (≈ −16 % au fond) ;
     ombres de contact conservées et mises à l'échelle.
  3. BARRE D'XP — plus grande, valeur « x / 50 XP » affichée dessus, reflet.
  4. MARCHE — génération d'une pose « mi-foulée » du héros (référence =
     hero.png actuel) ; alternance ~7 im/s en déplacement + balancement
     existant ; normalisation d'échelle entre textures de tailles différentes.
- Assets nécessaires : hero-walk.png (à générer, réf = hero.png, transparent).
- Risques : cohérence du personnage généré (visage/tenue) — critère de
  bascule : si la pose générée ne ressemble pas au héros, on garde le
  balancement seul et on le signale ; recadrage ENVELOP écarté pour ne pas
  couper l'UI.
- Critères d'acceptation : capture sans bandes noires à 1600×900, héros en
  deux poses distinctes selon les frames, barre XP lisible avec valeurs,
  perspective visible entre un personnage proche et lointain, build OK,
  0 erreur navigateur, aucune régression.
- Hors périmètre : 4 directions de marche dessinées, refonte des scènes.

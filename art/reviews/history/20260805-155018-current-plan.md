# Plan — Refonte AnswerOrb (questions/réponses en arène, 2026-08-05)

- Objectif : remplacer le bandeau de réponses séparé (couleur/forme à
  décoder) par des AnswerOrb — petites sphères 3D dans l'arène affichant
  directement le texte de la réponse, couleur non liée à la validité.
- Fichier concerné : `public/spike3d-arena.html` (seul fichier du jeu).
- Changements fonctionnels :
  - Données `QuestionDefinition`/`AnswerDefinition` (`isCorrect` par
    réponse, mode `SINGLE_TARGET`, `MULTI_TARGET` préparé mais pas
    implémenté), 14 questions de test toutes matières (maths, fractions,
    français, anglais, sciences, histoire, géographie).
  - AnswerOrb : chute depuis le haut à l'apparition, puis mouvement libre +
    rebond sur les bords de l'arène (vitesse faible, configurable via
    `ANSWER_ORB.speed`), taille plafonnée (`maxLabelWorldWidth`) quel que
    soit le texte.
  - Bandeau de question : réduction de police adaptative avant d'augmenter
    la hauteur, 2-3 lignes max (`fitQuestionBannerText`).
  - Capture correcte : tous les orbes de la question disparaissent, +10,
    rythme rapide vers la question suivante, aucun popup.
  - Capture incorrecte : flash rouge léger + -5, plus de gel de 2s
    (`applyWrongAnswerStun` allégé), le jeu n'est jamais interrompu.
  - Quiz post-manche migré vers la nouvelle structure de données.
  - Arène simplifiée pour ce test (`ARENA_SIMPLIFIED`) : caisses et caisse
    dorée désactivées, dangers réduits à 3 et rendus fixes (plus d'orbite).
  - Spawn des orbes : distance minimale ajoutée aux dangers fixes (évite le
    chevauchement orbe/météorite signalé en revue).
- Hors périmètre (reporté, décision Camille) :
  - Différenciation visuelle plus forte orbe-réponse vs avatar joueur
    (silhouette/palette actuellement proches) — changement de forme/socle
    des orbes, à trancher par Camille avant implémentation.
  - Réseau de lignes fines cyan/rose visible en diagonale dans l'arène,
    origine non identifiée dans le périmètre de cette tâche — signalé sans
    y toucher.
- Risques : aucune régression fonctionnelle attendue (déplacement,
  joystick, leaderboard, vie, pets — tous revérifiés).
- Critères d'acceptation : lecture rapide question → capture, pas de
  code couleur = validité, pas de coche/croix avant capture, orbes petites
  et lisibles, aucune interruption longue sur mauvaise réponse.

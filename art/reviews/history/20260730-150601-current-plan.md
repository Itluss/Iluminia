# Fiche d'itération — extension du monde : le Bourg (2026-07-30)

## Objectif utilisateur
« Étendre le monde : un village entier avec des bâtiments différents dans le
même style que notre premier template ; le personnage doit pouvoir se balader
dans ce village sur le chemin. »

## Choix d'architecture
Extension PAR ZONES (pas de régénération du décor actuel) :
- La place actuelle (VillageScene) reste intacte — aucun risque de régression.
- Nouvelle zone « Le Bourg » (BourgScene) : décor 2K généré par Banana avec
  le décor actuel comme référence de style, bâtiments différents (moulin,
  école, marché, chapelle, potagers).
- Passage : le chemin du nord de la place → fondu → le Bourg (entrée par le
  bas) ; retour par le même chemin.

## Expérience joueur attendue
Depuis la place, prendre le chemin qui monte entre les deux maisons ; l'écran
fond au noir ; on arrive dans le Bourg ; on s'y balade sur les chemins, entre
les bâtiments ; on redescend vers la place par le bas de l'écran.

## Changements fonctionnels
- Nouvelle scène BourgScene : décor natif ×1, bornes physiques, colliders
  hand-mappés, spawns héros+renard selon la provenance, caméra identique,
  HUD complet (état global partagé), zones de sortie (physics overlap).
- VillageScene : zone de sortie au nord + spawn de retour.
- Capture du Bourg possible via l'ancre d'URL `#bourg` (revue visuelle).

## Changements visuels
- Nouveau décor `bourg.png` (Banana 2K, refs = village-diorama-B2-clean +
  ref-village-diorama) : chemin entrant par le bas-centre, moulin, école à
  clocheton, rue de marché, chapelle, potagers, ruisseau.
- FX : sous-ensemble léger (lucioles, feuilles) — le gros des FX reste
  spécifique à la place (limitation assumée de cette itération).

## Assets nécessaires
- `public/art/generated/bourg.png` (à générer, vérifier composition + chemin
  d'entrée bas-centre AVANT code).

## Risques
- Composition générée sans chemin d'entrée au bas-centre → régénération.
- Colliders estimés (décor peint) → tour de marche de Camille.
- Transition de scène : état HUD/panneaux à réinitialiser proprement.

## Critères d'acceptation
- Build strict OK, 0 erreur console sur les DEUX zones.
- Capture du Bourg : décor non déformé, style cohérent avec la place,
  personnages à l'échelle, HUD présent.
- Aller-retour place ↔ bourg fonctionnel, spawns cohérents, gameplay de la
  place intact (Lina, question, récompenses).

# Eluminia

Un jeu vidéo dont la progression est alimentée par la scolarité réelle.

Les parents photographient les cours. L'IA comprend les compétences travaillées.
Le monde du jeu s'adapte et génère les missions de l'enfant.

- L'enfant vit une aventure — il ne « fait pas des exercices ».
- Le parent obtient un diagnostic pédagogique et un suivi des progrès.

## État

Projet créé le 2026-07-28. Phase : cadrage / POC.

Cible POC : CM1–CM2, mathématiques, une seule région, un village, quelques PNJ et missions.
